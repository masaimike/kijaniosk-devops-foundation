The Three ways in Devops are Flow,Feedback and Learning

1. Flow surrounds the idea of code moving smoothly from idea -> code -> build -> deploy -> monitoring.
In this design main,develop and feature branches separate stable production code from active development work.
This structure prevents unfinished features from accidentally reaching production.

2. Feedback is the ability to recognize errors early, pull requests ensure that code is reviewed before being merged.
This is achieved through the feature/starter-kit into develop branch ensuring it is reviewed.It will allow me to review changes

3. Learning is the idea of continuous learning from mistakes. The documentation is proper ground to allow developers avoiding the same mistakes.
